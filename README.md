# GiftCash Affiliate Website

A responsive static website starter for gift cards, reward programs, cashback education, and affiliate offers.

## Files
- `index.html` — homepage
- `style.css` — responsive design
- `script.js` — mobile navigation and category filters
- `disclosure.html` — affiliate disclosure starter
- `privacy.html` — privacy notice starter; customize before launch

## Before launch
- Replace guide placeholders with real partner offers only after approval and link verification.
- Add your approved affiliate URLs and follow each network's traffic rules.
- Disclose affiliate relationships clearly.
- Update the privacy notice to reflect your actual data practices.
- Never promise a reward unless the official partner terms support that claim.

## GitHub Pages
Upload all files to the root of your `giftcash` repository, commit to `main`, then open Settings → Pages. Select **Deploy from a branch**, choose `main` and `/(root)`, then Save. Wait for GitHub Pages to publish the URL.

Current cards are educational placeholders; no live affiliate URLs are configured.
